## Rules

1. Only edit your own page. Ask Ray for changes to the header, navbar, footer or `css/style.css`.
2. **Edit in github.dev:** on the repo page press `.` (full stop). When you stop, Source Control → type a message → **Commit & Push**. Open github.dev fresh each time so you start from everyone's latest work.
3. To see the site, use the GitHub Pages link (updates about a minute after a commit).
4. Build only inside the `<main class="container">` of your page.
5. File names in `images/` and `video/`: lowercase, no spaces (`lab-1.jpg`).
6. Keep the video under 25 MB.
7. Put a searchable comment above every Bootstrap feature, e.g. `<!-- CAROUSEL -->`, `<!-- GRID -->`, `<!-- ACCORDION -->`, `<!-- FORM -->`, `<!-- BREAKPOINT -->`.
