## Files to collect

Name each file **exactly** as below (lowercase, no spaces), put pictures in `images/` and the video in `video/`, then Commit & Push.

**Crop every picture to the exact size listed.** We aren't using custom CSS, so pictures only line up neatly if each group is the same size. Windows Photos (Edit → Crop → set the ratio) or any free online resizer will do it.
